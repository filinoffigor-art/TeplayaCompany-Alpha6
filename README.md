# Тёплая Компания 4.0 — Alpha 6 Full Demo

Готовый GitHub-пакет Android-приложения руководителя.

## Что это за версия
Alpha 6 — нативное Android-приложение без WebView. Оно работает на локальной демо-базе, чтобы можно было проверить всю иерархию экранов и действий до подключения Google Sheets.

Постоянный package/applicationId: `ru.teplayakompaniya.tk4`.

Версия: `6.0.0-alpha6`.

Поддержка: Android API 26+; targetSdk 34; compileSdk 35; Java 17.

## Главная бизнес-цепочка
`Лид → Замер → Запланирован → Подтверждён клиентом → ТЗ заполнено → В работе → Работы завершены → Оплачено/документы/расходы закрыты → Закрыт 100%`.

## Что работает в демо
- Главная руководителя: Оборот, Прибыль, Объекты в работе, Запланированные объекты, Планируется поступление.
- Живые KPI: Лиды, Замеры, Договоры, Средний чек, Дебиторка, Расходы.
- Объекты: статусы, поиск, карточка, звонок, карта, ТЗ, платежи, фотоотчёты, расходы.
- ТЗ: конкретные монтажники, сумма каждому, план по дням, график оплат, Android Share.
- Монтажники: рабочие дни, закрытые объекты, начислено/выплачено/к выдаче, инструмент, форма/СИЗ.
- Инженеры: административный интерфейс руководителя по работе инженера.
- Менеджеры: только согласованный каркас, без активного рабочего CRM-функционала.
- Финансы: приход, расход, внутренний перевод, подотчёт, общий остаток.
- Аналитика: оборот, дебиторка, план поступлений, остаток по договорам, фильтры.
- Календарь: загрузка монтажников и будущие объекты.
- Настройки: профиль, тема, роли, справочники, демо-синхронизация.
- Локальное сохранение демо-данных через SharedPreferences.

## Финансовые правила
- **Оборот** = все фактически полученные деньги за выбранный период, включая промежуточные платежи.
- **Прибыль периода** = фактический оборот − все фактические расходы периода.
- **Дебиторка** = только просроченный неоплаченный остаток этапов ТЗ.
- **Планируется поступление** = будущие неоплаченные этапы ТЗ.
- **Осталось получить** = сумма договора − фактические приходы по объекту.
- Внутренний перевод между подотчётными лицами не является расходом и не меняет общий остаток компании.
- Согласованная сумма монтажнику в ТЗ не является фактом выплаты.

## Android safe-area
Приложение не включает fullscreen/edge-to-edge. Статус-бар и нижняя системная панель остаются отдельными от контента; это соответствует требованию не заезжать под панели Android.

## Сборка в GitHub
Workflow: `.github/workflows/build-alpha6.yml`.

Он выполняет:
1. статические контрактные проверки;
2. JUnit-тесты финансовых правил;
3. Android Lint;
4. сборку APK;
5. проверку наличия APK;
6. загрузку артефакта `TeplayaCompany-v6.0.0-alpha6.apk`.

## Документация
См. папку `docs/` — там зафиксированы экранная иерархия, роли, формулы, модель данных, схема будущей Google Sheets и чек-лист приёмки.

## Google Sheets
Папка `backend/google_apps_script/` содержит каркас API. Alpha 6 пока не вызывает его из Android — это следующий технический этап после утверждения демо-функционала.
