## Реализовано в Android

Главная сетка и широкая карточка плана, bottom navigation, меню, pull refresh, loader, haptic/ripple, системный выбор фото с persistable URI; нет загрузки demo fallback. Кэш и ответы разделены по аккаунту/периоду. Списки объектов, детали финансовых операций, фильтры центра событий, режимы и диапазоны календаря. Даты вводятся через DatePicker. Settings и Bitrix24 показывают реальное отсутствие серверного контракта.

Подотчёт допускает отрицательное значение, показывает невозмещённые средства и поля истории без выдуманных нулей. Формы возмещения с выбором источника, перемещения с расчётом DAILY/FIXED, создания/дней наёмника, promotion встроены в существующие экраны. Запись включается только по capability backend; сейчас она недоступна.

## Открытые требования, не выдавать за готовые

- Оригинальный ключ подписи Alpha6.1 не найден. На реальном телефоне обновление поверх установленного APK не проверено.
- Полный серверный RBAC/row scoping ещё отсутствует. Manager/Installer/Engineer не получают доступ к общему набору данных в UI, но действующий сервер сам пока возвращает слишком широкий ответ. Нужна серверная проверка, UI не является защитой API.
- Новые финансовые/кадровые операции, audit и idempotent recovery требуют backend из STAGE1_BACKEND_CONTRACT.md. Миграция подготовлена, production не изменён.
- Существующее ТЗ read-only: текущий saveTechTask пересоздаёт children. Новое ТЗ использует существующий контракт; произвольные этапы с диапазонами/стоимостью, редактирование с revision, отправка и workflow readiness ещё требуют saveTechTaskV2. PDF использует системную печать; share — текст сохранённых данных.
- Корректировки финансовых операций с причиной/audit не активированы без серверной поддержки. Списки операций ограничены текущим API, не полная история.
- Комбинируемые аналитические фильтры, месячная группировка квартала/года, детальная воронка, зарплата менеджера, полнота/quality KPI и собственные показатели ограниченных ролей требуют контракта API.
- Производственный календарь показывает переданные диапазоны; контроль конфликтов бригад/фактических дней и новые кадровые события требует сервера.
- Настройка масштаба текста/контраста/подсказок, редактирование пользователей/ролей/справочников, backup UI, Bitrix24 sync пока не подключены.
- Реальные sync/mutation, фото и PDF на пользовательском устройстве не тестировались; тесты CI офлайн и не записывают production Sheets. Скриншоты с пометкой QA используют фикстуры только в отдельном test APK.
