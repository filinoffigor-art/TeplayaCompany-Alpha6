# Alpha 6 — чек-лист приёмки

## Android / сборка
- [ ] Нет WebView.
- [ ] APK собирается в GitHub Actions.
- [ ] Unit tests = success.
- [ ] Android Lint = success.
- [ ] Контент не перекрывает status bar/navigation bar.
- [ ] На разных Android-экранах нет горизонтального выхода.

## Главная
- [ ] Порядок: Оборот / Прибыль / Объекты в работе / Запланированные объекты / Планируется поступление.
- [ ] Все KPI кликабельны.
- [ ] Все карточки одного визуального размера в своей сетке.

## Оборот
- [ ] Общий оборот.
- [ ] Промежуточные платежи.
- [ ] Оплаты по закрытым объектам.
- [ ] Переход до объекта/платежа.

## Объекты
- [ ] Фильтры работают.
- [ ] Поиск по клиенту/адресу/городу/телефону.
- [ ] Создание объекта.
- [ ] Смена статуса.
- [ ] В работу нельзя без полного ТЗ (production requirement).

## ТЗ
- [ ] Конкретные монтажники.
- [ ] Сумма каждому.
- [ ] План по дням.
- [ ] График оплат.
- [ ] Поделиться через Android Share.

## Финансы
- [ ] Приход.
- [ ] Расход.
- [ ] Передача в обе стороны.
- [ ] Передача не меняет общий остаток.
- [ ] Приход/расход привязывается к объекту/ответственному в production.

## Монтажники
- [ ] Всего / на объектах / закрыто / к выдаче.
- [ ] Карточка сотрудника.
- [ ] Выплаты уменьшают к выдаче.

## Аналитика / внимание
- [ ] Дебиторка — только просрочка.
- [ ] План поступлений — только будущие этапы.
- [ ] Лиды/замеры freshness alerts.
- [ ] 7 дней без движения по договорам.
