# Будущая структура Google Sheets

Рекомендуемые вкладки:
1. Objects
2. TechnicalTasks
3. TaskDays
4. ObjectInstallers
5. PaymentStages
6. MoneyOperations
7. AccountableBalances
8. Leads
9. Surveys
10. Contracts (при необходимости как представление, не дубль объекта)
11. Installers
12. Engineers
13. Managers
14. Inventory
15. InventoryAssignments
16. PPE
17. Dictionaries
18. Users
19. AuditLog
20. SyncQueue / SyncLog

Источник: существующая рабочая таблица пользователя. При интеграции нельзя уничтожать текущие данные, формулы, дашборды и учёт. Добавлять структуру безопасно через новые вкладки/колонки и технические ID.

Связи делаются только по ID, а не по адресу или номеру строки.
