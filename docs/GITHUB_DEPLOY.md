# Загрузка Alpha 6 в GitHub

## Вариант для чистого репозитория
1. Создать пустой репозиторий, например `TeplayaCompany-Alpha6`.
2. Распаковать ZIP-пакет.
3. Загрузить **содержимое** папки в корень репозитория, а не сам ZIP.
4. Проверить, что в репозитории есть `.github/workflows/build-alpha6.yml` и `app/`.
5. Commit в `main`.
6. Открыть вкладку Actions / Действия.
7. Workflow `Build TK4 Alpha6 Full Demo` запустится автоматически после изменения app/build-файлов; его также можно запустить вручную.
8. После зелёной сборки артефакт называется `TeplayaCompany-v6.0.0-alpha6` и содержит APK.

## Не смешивать
В новом репозитории не нужны Alpha1–Alpha5, старые WebView-папки и старые workflows.
