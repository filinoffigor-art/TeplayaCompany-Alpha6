# Финансовые формулы

- `Оборот(period) = Σ фактических INCOME с датой в period`.
- `Расходы(period) = Σ фактических EXPENSE с датой в period`.
- `Прибыль(period) = Оборот(period) - Расходы(period)`.
- `Осталось получить(object) = Договор - Σ фактических поступлений object`.
- `Дебиторка(today) = Σ max(0, PlannedAmount - ActualAmount)` только для этапов с PlannedDate < today.
- `Планируется поступление(today) = Σ max(0, PlannedAmount - ActualAmount)` для этапов с PlannedDate >= today.
- `К выдаче монтажнику = Начислено - Авансы - Частичные выплаты - Финальные выплаты`.
- `Общий остаток = Σ остатков подотчётных лиц/касс`.
- Внутренний transfer: уменьшает один подотчёт, увеличивает другой, не влияет на общий остаток и расходы.

Закрытие объекта 100% требует не только 100% оплаты, но и закрытых работ/расходов/обязательных отчётов.
